## 5) Titik Berat per MK

### Konsep Sistem Informasi (136 jam)
- **Minggu 1-4**: Aktif inti -- pengenalan, observasi, user story, peta komponen SI
- **Minggu 5-7**: Finalisasi D2, peta komponen SI mendalam, sesi critique
- **Minggu 8**: Gate Review 1 -- D1, D2 sign-off
- **Minggu 9-16**: Review minor, dampingi lintas MK

### Dasar Pemrograman (181 jam)
- **Minggu 1-2**: Pengenalan komputasi, tipe data
- **Minggu 3-7**: Desain IPO/flowchart, persiapan D3
- **Minggu 8**: Gate Review 1 -- review desain
- **Minggu 9-13**: Pengkodean D3, uji, walkthrough, Gate 2
- **Minggu 14-16**: Finalisasi, Demo Day

### Komunikasi Profesional & Kerja Tim (90 jam)
- **Minggu 1-7**: Pembentukan tim, norma, komunikasi, sesi critique
- **Minggu 8**: Gate Review 1 -- observasi presentasi
- **Minggu 9-15**: Critique, refleksi, D5, persiapan presentasi
- **Minggu 16**: Postmortem, Demo Day

### Bahasa Inggris (90 jam)
- **Minggu 3-4**: Pengenalan penulisan profesional
- **Minggu 9-12**: Penulisan executive summary
- **Minggu 14-16**: D4 (pitch deck), rehearsal, Demo Day
